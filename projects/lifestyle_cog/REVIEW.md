# Review: Lifestyle-Based COG Stratification

## Summary

A thorough, well-scoped, and clearly written pangenome study that asks a focused question (does bacterial lifestyle shape COG-level functional partitioning?) and answers it across 2,529 species in 10 phyla. The work follows the BERIL three-file structure (README / RESEARCH_PLAN / REPORT) cleanly, pre-registers three hypotheses, runs the analysis end-to-end with saved notebook outputs, and reports both expected results (H1–H3 all supported) and a striking unexpected finding (S "function unknown" is the most lifestyle-discriminating category). The REPORT is unusually disciplined about caveats (clinical-isolate over-sampling, Cyanobacteriota outlier, S-category annotation lag). Main areas for improvement are: (1) a few in-notebook "Findings" templates were never filled in, (2) the enrichment-score formula has a small-denominator distortion that should be flagged, (3) the multi-character COG splitting double-counts clusters and is undocumented, (4) the Reproduction section is too thin, and (5) effect sizes (only p-values and median differences) could be strengthened.

## Code Quality

**Strengths:**

- Correct EAV pivot of `ncbi_env` with `MAX(CASE WHEN harmonized_name = ... THEN content END)` pattern (NB01 cell 16). This matches the pitfalls.md recommendation.
- Correct use of `gene_cluster_id = query_name` join with `eggnog_mapper_annotations` (NB02 cell 4), avoiding the gene_id-vs-cluster_id pitfall.
- Correct species-level filtering via `gtdb_species_clade_id IN (...)` with batching (BATCH_SIZE = 20) to keep IN-clauses manageable; uses quoted string literals so the `--` in species IDs is not a SQL-comment issue.
- Explicit exclusion of `'-'` (no-COG) annotations and null COG categories before counting (NB02 cell 4).
- BH-FDR correction is computed manually but **correctly**, including the reverse-cummin monotonicity step (NB02 cell 12).
- Phylum-stratified consistency analysis is implemented with a sensible `≥3 species per group` minimum (NB03 cell 5), and the direction-consistency heuristic (≥70%) is a reasonable robustness check.
- Numbers in REPORT.md match the notebook outputs (2,529 species; 1,705 host vs 824 free; 279,547 genomes with lifestyle metadata; 23,900 species with clear assignment).

**Issues / things to flag:**

1. **Pseudocount distorts low-coverage enrichment scores (NB02 cell 9).** The enrichment formula `(prop_accessory - prop_core) / (prop_core + 1e-4)` blows up when `prop_core` approaches zero. The A-category enrichment of −2.40 reported in REPORT.md is consistent with this distortion (A has very limited bacterial coverage — n = 1,606), and the formula will produce systematically inflated magnitudes for rare COGs. A log-ratio (`log2((prop_acc + ε) / (prop_core + ε))`) with a larger ε (e.g., 1e-3 or a count-based pseudocount) would be more stable. At minimum, this denominator behavior should be documented in REPORT.md §Limitations.

2. **Multi-character COG splitting double-counts gene clusters (NB02 cell 7).** When a gene has COG_category = "LV", the code emits two rows (one for L, one for V), each with the full `cluster_count`. This means every "membership" is counted in both compartments. This is a defensible choice (it reflects functional membership rather than primary assignment) but it inflates the denominator in proportion calculations, and it is not noted in REPORT.md or RESEARCH_PLAN.md. Either (a) document this convention explicitly, or (b) report the per-letter-membership fraction so a reader can see how much it matters. A sensitivity check using only single-letter COG annotations would be valuable.

3. **`scipy.stats.false_discovery_control` is imported but not used (NB02 cell 12).** The manual BH calculation is correct, so this is a cosmetic cleanup — but using the library function would be clearer and remove a dead import.

4. **Effect sizes are not reported.** The REPORT tables show p-values and median differences only. For a 2,529-species comparison, almost any direction will pass p<0.05, so the meaningful question is effect magnitude. A rank-biserial correlation (which falls out of the Mann-Whitney U directly: `r = 1 − 2U/(n1·n2)`) or Cliff's delta would add interpretability. The very small median differences in H3 (Δ = −0.065 on a 0–1 fraction) are highly significant but modest in absolute terms — readers benefit from a standardized effect size.

5. **Lifestyle classification has minor edge cases.**
   - `host_keywords` includes `'gut'` and `'intestin'` — a sample annotated `isolation_source = 'gut metagenome'` with no host attribute will be classified as host-associated, which is intended, but `'soil intestine'` (rare) would too.
   - `has_valid_host(host_col)` accepts strings like `"not known"` (seen in cell 18 sample output) as a valid host, since `"not known"` is not in the `na_values` list. This may have inflated host-associated counts at the genome level (though majority vote at species level dampens this).
   - The `na_values` check is `.isin()`, which is case-sensitive on the substring after `.lower()` is applied — so `"Not Applicable"` becomes `"not applicable"` and matches. OK. But values like `"not applicable [GAZ:none]"` or `"missing: control sample"` will NOT match the sentinels.

6. **Numeric column types after CSV round-trip.** NB02 cell 15 and NB03 cell 7 divide `no_core / no_gene_clusters` without an explicit numeric cast. This works because `pd.read_csv` auto-coerces numeric columns, but the original Spark query (NB01 cell 22) doesn't `CAST(...)` either. If `pangenome` columns ever become string-typed (a documented pitfall), the division would silently fail. Adding `pd.to_numeric(..., errors='coerce')` is a one-line robustness fix.

7. **`.toPandas()` inside a per-batch loop (NB02 cell 4) is fine here** because each batch returns a small aggregate (per-species × per-compartment × per-COG counts), but for transparency it would help to print the per-batch row count and total at the end. The code already does this.

8. **In-notebook "Findings" templates were never filled in (NBs 01, 02, 03).** Each notebook ends with a markdown cell containing template lines like `- **H1 (Defense V enrichment)**: ___`. These were superseded by REPORT.md, but a reader skimming the notebooks gets the impression the analysis was abandoned. Either delete the placeholder cells or replace them with a one-sentence pointer to REPORT.md.

## Findings Assessment

The findings are well-supported and well-presented. All three pre-registered hypotheses are supported with very low p-values, and the report does not over-claim: the phylum-stratified consistency check (8/10, 9/10, 6/8 phyla agreeing) is the correct way to argue for biological generality beyond phylum confounding. The Cyanobacteriota outlier for H3 is explicitly called out and explained (host-associated Cyanobacteria include reduced endosymbionts that violate the facultative-host-associated assumption of the analysis).

Specific strengths in the findings section:

- **The S (function unknown) discussion is unusually honest.** The report explicitly notes that the host-vs-free S gap may reflect under-study of clinical isolates rather than novel biology, and points to the `functional_dark_matter` NB12 evidence that 83.7% of "dark" genes are annotation-lag. This is the right epistemic stance for a category that carries the strongest signal but the weakest mechanistic interpretation.
- **The H3-reversal-from-classical-streamlining discussion is correct and important.** The ≥10-genome filter excludes obligate endosymbionts, so the "host has smaller core fraction" finding lives in a different regime from the McCutcheon/Moran/Klasson literature on reductive evolution.
- **The genome-count confound is addressed quantitatively.** Median 20 vs 14 genomes/species is acknowledged, and the report correctly argues that uniform amplification cannot explain the differential COG composition.

Weaknesses:

- **No explicit FDR threshold on the phylum-stratified tests.** Each phylum × COG combination is tested with Mann-Whitney without multiple-testing correction (NB03 cell 5). With 10 phyla × 12 key COGs = 120 tests, some of the per-phylum p-values reported in REPORT.md (e.g., Campylobacterota H3 p = 0.034) would not survive multiple correction. The direction-consistency heuristic partially mitigates this, but a Holm or BH correction across the within-phylum tests would tighten the interpretation.
- **Annotation completeness as a confounder is mentioned in RESEARCH_PLAN.md §Confounders but not directly tested.** The fraction of gene clusters with a COG annotation per species could differ systematically by lifestyle (since clinical isolates may be better-annotated for known systems but worse-annotated for novel ones). A two-line check of `annotated_cluster_count / total_cluster_count` by lifestyle would close this gap.
- **The "S inflation is real compositional shift, not differential annotation coverage" claim in §Striking unexpected finding** relies on the fact that proportions sum to 1.0 within annotated genes — but if annotated-vs-unannotated rates differ by lifestyle, this normalization itself hides a coverage effect. The argument is plausible but would be stronger with the explicit annotation-coverage check above.
