# NMDC BioSamples

Provider: NMDC / NCBI · [Website](https://microbiomedata.org/)

## Description

Harmonized NCBI BioSample metadata from the National Microbiome Data Collaborative. Standardized attributes, environmental triads, and dimensional statistics for biosample integration.

## Purpose

Standardize biosample metadata for cross-study comparisons. Enable sample discovery and integration across microbiome studies.
